Exemple d'intégration dans une page web statique

Cet exemple montre comment intégrer la visualisation interactive 3D de l'identité de Kaya dans n'importe quel site web statique, blog (Jekyll, Hugo, WordPress, etc.) ou portail documentaire via une simple balise <iframe>.

Code d'intégration HTML

Pour insérer cette visualisation sur votre page statique :

<!-- Conteneur responsive pour la visualisation Kaya 3D -->
<div style="position: relative; width: 100%; height: 600px; border-radius: 10px; overflow: hidden; border: 1px solid #e5e7eb;">
  <iframe 
    src="path/to/kaya/index.html?embed=true" 
    style="width: 100%; height: 100%; border: none;"
    title="Visualisation 3D de l'Identité de Kaya"
    loading="lazy">
  </iframe>
</div>
